v1.1.0  2026-10-11

1. 全新跨平台版本：同步支持 Windows、Linux（AppImage / .deb）和 macOS（通用版，Intel 与 Apple Silicon 同一安装包）
2. 三端功能、界面、版本号完全一致：SSH 多标签终端、AI 运维助手、SFTP 上传、命令补全、服务器实时状态监控、在线自更新
3. 在线更新按平台自动选择安装包，全部带 SHA256 校验、断点重试与替换保护
4. Linux 数据保存在 ~/.config/lindong-ssh，macOS 保存在 ~/Library/Application Support/lindong-ssh，Windows 仍在程序同目录
5. 说明：macOS 版暂未购买 Apple 开发者证书，首次打开请右键 -> 打开；Linux AppImage 可直接双击运行，.deb 适用于 Ubuntu/Debian

v1.0.6  2026-10-11

1. 修复部分用户在线更新失败的问题：下载链路改为强制回源（避开 CDN 边缘缓存到损坏文件的情况）
2. 安装包下载新增 SHA256 完整性校验与文件大小校验，损坏/不完整自动重试 3 次
3. 替换安装阶段新增文件锁重试（杀毒软件占用时最多等待 40 秒）、更新日志（%TEMP%\lindong-ssh-update.log），替换失败会自动重启旧版本，程序不会消失
4. 服务端安装包改为不缓存，今后新版本发布即时生效

v1.0.5  2026-10-11

1. 服务器运行状态实时监控：侧边栏新增状态汇总条，随时显示在线/离线/检测中/总数
2. 点击汇总条打开「服务器运行状态」面板：逐台展示状态灯、实时延迟、最后检测时间（刚刚/x秒前），并显示距下次自动检测倒计时
3. 自动检测间隔由 90 秒缩短为 30 秒；终端断线后立即重测该服务器；切回窗口立即刷新
4. 服务器卡片悬停可查看完整地址与最后检测时间；点击状态面板中的服务器可直接连接
